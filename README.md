# Vaibhav Singh | Portfolio

Personal portfolio: a single static page with an animated "actual vs forecast" load-curve background.

**Live:** https://singhvaibhav924.github.io

Structure adapted, with permission, from [0xKushwaha/portfolio](https://github.com/0xKushwaha/portfolio).

## Files
- `index.html`: the whole site (HTML, CSS and JS in one file; fonts from Google Fonts)
- `resume.pdf`: downloadable resume
- `og-image.png`: link preview image for LinkedIn, WhatsApp and X
- `.nojekyll`: tells GitHub Pages to serve files as-is

## Run locally
No build step. Open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
```

## Update
- **Resume:** replace `resume.pdf` (keep the name) and push.
- **Analytics:** GoatCounter, dashboard at https://singhvaibhav924.goatcounter.com

Every push to `main` redeploys automatically.
